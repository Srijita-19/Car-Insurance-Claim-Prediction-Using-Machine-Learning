# Car Insurance Claim Prediction Using Machine Learning

## Project Overview

This project applies data analytics and machine learning techniques to analyse automobile insurance customer and policy information and predict the likelihood of an insurance claim.

The analysis focuses on identifying relationships between customer characteristics, vehicle-related attributes, policy information and claim outcomes.

The project demonstrates how exploratory data analysis, data preprocessing and machine learning classification can be applied to an insurance analytics problem.

## Business Problem

Insurance companies need to estimate the likelihood of claims in order to manage risk, understand customer segments and support efficient insurance operations.

A better understanding of claim patterns can help insurers:

* Assess customer risk
* Improve underwriting analysis
* Identify higher-risk customer segments
* Support pricing decisions
* Improve portfolio monitoring
* Allocate operational resources
* Develop data-driven risk-management strategies

The objective of this project is to analyse historical insurance data and develop a predictive framework for identifying customers who are more likely to make an insurance claim.

## Objectives

The project aims to:

1. Understand the insurance dataset and its variables.
2. Analyse customer and policy characteristics.
3. Perform data cleaning and preprocessing.
4. Explore relationships between customer attributes and claim outcomes.
5. Identify patterns associated with insurance claims.
6. Develop a machine learning classification approach.
7. Evaluate the predictive performance of the model.
8. Interpret the results from an insurance-risk perspective.
9. Generate business insights from the analysis.

## Dataset / Database Overview

The project uses a structured automobile insurance dataset containing customer, policy and vehicle-related information.

The dataset includes variables representing relevant customer and insurance characteristics and a target variable indicating whether an insurance claim was made.

**Major Data Categories**

| Category              | Examples                                        |
| --------------------- | ----------------------------------------------- |
| Customer Information  | Demographic/customer characteristics            |
| Vehicle Information   | Vehicle-related characteristics                 |
| Policy Information    | Insurance/policy attributes                     |
| Financial Information | Relevant financial or premium-related variables |
| Claim Information     | Historical claim outcome                        |

**Target Variable**

The target variable represents whether an insurance claim was made.

The machine learning problem is therefore treated as a classification problem.

## Analysis Performed

**1. Data Understanding**

The analysis began by examining:

* Dataset structure
* Number of observations
* Variables
* Data types
* Target variable
* Descriptive statistics

**2. Data Preprocessing**

The dataset was prepared for analysis and machine learning.

The preprocessing workflow included relevant steps such as:

* Data inspection
* Data cleaning
* Variable preparation
* Categorical-variable handling where required
* Feature preparation
* Target-variable definition

**3. Exploratory Data Analysis**

EDA was performed to understand customer and policy characteristics and their relationship with claim outcomes.

The analysis considered relevant factors from the available dataset, including:

* Customer characteristics
* Vehicle characteristics
* Insurance-policy attributes
* Other available explanatory variables
* Claim status

The purpose was to identify meaningful patterns and potential risk indicators.

**4. Claim Pattern Analysis**

The project examines differences between customers who made claims and those who did not.

This helps identify characteristics that may be associated with higher claim incidence.

**5. Machine Learning**

A classification-based machine learning framework was applied to predict insurance claim outcomes.

The general workflow involved:

1. Selecting explanatory variables.
2. Defining the target variable.
3. Preparing the dataset.
4. Splitting the dataset for training and evaluation.
5. Training the classification model.
6. Generating predictions.
7. Evaluating model performance.

## Key Findings / Results

The analysis demonstrates how customer, vehicle and insurance-related characteristics can be examined to understand differences in claim behaviour.

Key observations from the project include:

* Insurance claim behaviour can be influenced by multiple customer and policy characteristics.
* Exploratory analysis can reveal meaningful differences between claim and non-claim observations.
* Machine learning can provide a structured approach for predicting claim outcomes.
* Data preprocessing and feature preparation are important components of insurance predictive modelling.
* Predictive results can potentially support risk segmentation and insurance portfolio analysis.

## Limitations

This project is an educational machine learning analysis based on historical data.

Potential limitations include:

* Historical patterns may not represent future claim behaviour.
* Model performance depends on the available features and dataset quality.
* Predictive relationships should not automatically be interpreted as causal relationships.
* Further validation would be required before using such a model in a production insurance environment.
* Real-world insurance models require appropriate governance, validation, fairness assessment and monitoring.

This project demonstrates how data analytics and machine learning can be applied to insurance claim prediction.
